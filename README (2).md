- 🗄️ **Scalable storage:** S3 and DynamoDB handle up to 1TB of data a month.
- ❄️ **Analysis-ready:** Data lands in Snowflake for end-to-end querying, with fine-grained AWS access control.

### [🚕 End-to-End Uber Data Analytics Pipeline](https://github.com/YuvaKrishnaThanneru/End-to-End-Uber-Data-Analytics-pipeline)
- 🔄 **Orchestration:** Mage on Google Compute Engine runs the extract and transform steps.
- 🧱 **Modeling:** A fact and dimension model in BigQuery.
- 📊 **Reporting:** A Looker dashboard for trip and fare trends.

### [🎥 YouTube Data Analysis with AWS ETL](https://github.com/YuvaKrishnaThanneru/Youtube-Data-Analysis-Utilizing-ETL)
- 📥 **Data lake:** 500,000 video records from multiple sources, centralized in Amazon S3.
- 🤖 **ETL:** AWS Glue and Lambda automate transformation for near real-time updates.
- ⚡ **Querying:** Athena reduced query times by 70%, with IAM for secure access.
- 📊 **Reporting:** An Amazon QuickSight dashboard for video trends, categories and metrics.

### [🔍 Research Paper Search Engine](https://github.com/YuvaKrishnaThanneru/research-paper-search-engine)
